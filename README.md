# CosmicGuide 🔮

CosmicGuide is a modern astrology mobile application that delivers personalized horoscopes, compatibility insights, tarot readings, and kundli matching powered by AI and traditional astrology logic.

The goal of this project is to create a highly engaging astrology platform combining mystical guidance, personality insights, and relationship compatibility.

---

## Core Features

* Daily horoscope predictions
* Personalized AI fortune generator
* Tarot card of the day
* Zodiac compatibility checker
* Kundli matching (Gun Milan)
* Personality insights
* Astrology story feed
* Push notifications
* Premium astrology reports

---

## Target Users

* Astrology enthusiasts
* Users seeking daily guidance
* Couples checking compatibility
* Marriage kundli matching (India)
* People interested in personality insights
